# Автоматическое оглавление со ссылками — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** В режиме «Оформить» сервис вставляет после «СОДЕРЖАНИЕ» настоящее оглавление Word: пункты — кликабельные ссылки на заголовки, номера страниц правильные, в DOCX и в PDF.

**Решения (согласованы в чате + итоги пробы LibreOffice):**
- Исходный DOCX не пересохраняется через LibreOffice (LO переписывает styles.xml и округляет поля). Оглавление строит наш код; LibreOffice используется только чтобы узнать номера страниц и построить PDF.
- Заголовки получают стили Word «Heading 1/2/3» (структурные элементы — уровень 1); внешний вид — по профилю, прямым форматированием, как сейчас.
- Оглавление — поле `TOC \o "1-3" \h \z \u` с готовым (кэшированным) результатом: строки «Заголовок … номер» с `w:hyperlink w:anchor="_Toc…"` на закладки у заголовков, табуляция с точками до номера у правого поля.
- Номера страниц: воркер открывает копию результата в LibreOffice (headless, UNO, свой профиль на вызов), обновляет индексы, читает номер страницы каждой закладки `_Toc…`, вписывает номера в наш DOCX. PDF строится из той же копии после обновления.
- Если LibreOffice недоступен или упал — номера не вписываются, в `word/settings.xml` ставится `<w:updateFields w:val="true"/>` (Word предложит обновить при открытии), в отчёт — предупреждение «Номера страниц в оглавлении обновятся при открытии в Word».
- Ручное содержание (строки после «СОДЕРЖАНИЕ» до следующего раздела) заменяется автоматическим. Нет раздела «СОДЕРЖАНИЕ» — оглавление не вставляется; если профиль требует раздел (`headings.structural`) — существующее замечание.
- Проверка неизменности текста: строки оглавления — сгенерированный текст, `textguard` их исключает (сравнение слов идёт без раздела СОДЕРЖАНИЕ до и после).
- Правило в профиле: `toc` = `{"levels": 3, "hyperlinks": true}`, severity `recommendation`, во всех встроенных профилях; во фронтенде — поле «Уровней в оглавлении» (fixed 3) и «Ссылки» (fixed да).

## Global Constraints
- Закладки `_Toc<8 цифр>` уникальны; повторный «Оформить» не плодит закладки и не дублирует оглавление (идемпотентность).
- Время LibreOffice на документ ≤ JOB_TIMEOUT/2; процесс soffice всегда убивается (группа процессов), профиль во временном каталоге удаляется.
- Комментарии Word и прочее содержимое DOCX не теряются.

### Task 2: Воркер — номера страниц и PDF через LibreOffice
**Files:** `backend/gostdoc_api/lo_pages.py` (UNO-скрипт по итогам пробы `/tmp/.../tocspike/up.py`), `pdf.py`, `worker.py`, тесты `tests/api/test_lo_pages.py`.
**Interfaces:** `lo_pages.page_numbers_and_pdf(docx_path, out_pdf, *, soffice, timeout_s) -> dict[str,int]` — запускает soffice с UNO-каналом, обновляет индексы, читает страницы закладок `_Toc…`, сохраняет PDF; при ошибке — `PdfError`. Воркер: после `process` для mode=format → `page_numbers_and_pdf` → `set_page_numbers` → сохранить DOCX; при ошибке — `set_update_fields` + предупреждение, PDF старым способом.
